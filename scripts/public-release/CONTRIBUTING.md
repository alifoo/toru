# Contributing

Use Node 24 and the pnpm version in package.json. Install with the frozen lockfile, build, typecheck and run tests before submitting a change. Include meaningful regression tests for browser behavior, ownership, quota or recovery changes. Describe what changed, why, and how you verified it.

Contributions to original engine code use MIT. Keep upstream license notices and identify copied code. Do not submit private tokens, cookies, account data, product recordings or proprietary artwork. Avoid modifying vendored code without a documented reason and an upstream reference.

Reports should include versions, safe error codes, a minimal demo fixture and reproduction steps. Do not paste raw browser state or credentials. See SECURITY.md for sensitive issues. There is no contribution-response SLA during the beta.
